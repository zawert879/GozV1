# Слеш команды Game of Zawert

Используйте эти команды для быстрого доступа к функциям GOZ в Claude Code.

## Доступные команды

### `/goz-character`
**Создать персонажа по концепции**

Использование:
```
/goz-character ловкий эльф-вор со знанием магии
```

Что происходит:
1. Claude прочитает GOZ_Character_Generator.md
2. Проанализирует вашу концепцию
3. Распределит 50 ОП между характеристиками и умениями
4. Вернет персонажа в виде таблицы с полными расчётами

Пример:
```
/goz-character сильный варвар, глупый, но харизматичный
```

---

### `/goz-item`
**Создать предмет или снаряжение**

Использование:
```
/goz-item ледяной посох для среднего уровня в фэнтези сеттинге
```

Что происходит:
1. Claude выберет уровень (Tier)
2. Применит теги
3. Рассчитает ОБ
4. Вернет предмет в формате таблицы

Пример:
```
/goz-item кибернетическое оружие для киберпанка, малого уровня, быстрое и точное
```

---

### `/goz-skill`
**Создать новое умение**

Использование:
```
/goz-skill способность поглощения магии, защитное умение
```

Что происходит:
1. Claude создаст новое умение
2. Определит связанную характеристику
3. Опишет эффект и использование
4. Даст примеры

Пример:
```
/goz-skill боевой рывок, позволяет быстро атаковать несколько врагов подряд
```

---

### `/goz-balance-check`
**Проверить баланс персонажа или предмета**

Использование:
```
/goz-balance-check [вставьте содержимое персонажа или предмета]
```

Что происходит:
1. Claude проверит все расчёты
2. Убедится в правильности баланса
3. Даст рекомендации по улучшению
4. Вернет подробный отчёт

Пример:
```
/goz-balance-check Воин: СЛ 12, ЛВ 10, ИН 10, ЗД 11, Оружие ближнего боя Уровень 3, Броня средняя Уровень 2...
```

---

### `/goz-expansion`
**Добавить контент в Sample_Adventure.md**

Использование:
```
/goz-expansion [вставьте одобренный контент]
```

Что происходит:
1. Claude подготовит контент для добавления
2. Выберет правильный раздел
3. Сохранит формат таблицы
4. Обновит комментарии ОБ

Важно: Используйте эту команду ТОЛЬКО после одобрения контента пользователем!

---

### `/goz-party`
**Создать сбалансированную группу персонажей**

Использование:
```
/goz-party группа из 4 персонажей: воин, маг, вор и целитель
```

Что происходит:
1. Claude создаст каждого персонажа
2. Убедится, что они дополняют друг друга
3. Проверит баланс группы
4. Даст рекомендации по тактике

Пример:
```
/goz-party группа для киберпанка: лидер, боец с кибер-имплантами, хакер, медик
```

---

### `/goz-rules`
**Объяснить правило GOZ**

Использование:
```
/goz-rules как рассчитывается броня и инициатива
```

Что происходит:
1. Claude найдёт правило в GOZ_v1_Rules.md
2. Даст чёткое объяснение
3. Приведёт примеры
4. Объяснит намерение за правилом

Пример:
```
/goz-rules можно ли менять умения после создания персонажа
```

---

### `/goz-print`
**Подготовить контент для печати**

Использование:
```
/goz-print [вставьте контент для печати]
```

Что происходит:
1. Claude оптимизирует формат для печати
2. Сделает его компактным
3. Разобьёт на логические секции
4. Вернет готовый текст

Пример:
```
/goz-print подготовь шпаргалку для боевой системы на одну страницу
```

---

## Быстрые советы

✓ **Используйте цитаты** при вставке многострочного контента:
```
/goz-balance-check
"Вставьте здесь весь контент персонажа
или предмета для проверки"
```

✓ **Будьте конкретны** — чем подробнее описание, тем лучше результат:
- Вместо: `/goz-item меч`
- Напишите: `/goz-item боевой меч среднего уровня, колющий и режущий, для киберпанка`

✓ **Проверяйте баланс** перед добавлением в Sample_Adventure.md:
```
/goz-balance-check [ваш предмет]
```

✓ **Сохраняйте контекст** — Claude помнит о системе ОП и ОБ в контексте проекта

---

## Расширение списка команд

Если вам нужна новая команда, напишите:
```
Добавь слеш команду /goz-[название] для [описание функции]
```

Примеры:
- `/goz-npc` — создать НИП для приключения
- `/goz-quest` — создать квест с наградами
- `/goz-monster` — создать монстра-врага
- `/goz-loot` — создать дроп добычи

---

**Все команды работают с русским языком и следуют правилам из GOZ_Framework!**
