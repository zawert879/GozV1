# Combat Calculator

Калькулятор для боевых расчётов в Game of Zawert.

## Использование

```
/combat-calculator [команда] [параметры]
```

## Команды

- `initiative СЛ=12 ЛВ=10 броня=heavy` — инициатива
- `damage СЛ=13 оружие=меч броня=средняя` — урон от атаки
- `attack СЛ=12 умение=2` — целевое число для атаки
- `hp СЛ=12 ЗД=10` — очки здоровья
- `movement ЛВ=13 броня=light` — очки передвижения
- `magic ИН=12 умение=2` — целевое число для магии

## Примеры

- `/combat-calculator initiative ЛВ=12 броня=light`
- `/combat-calculator damage СЛ=13 оружие=меч броня=кольчуга`
- `/combat-calculator hp СЛ=14 ЗД=12`
- `/combat-calculator magic ИН=13 умение=3`

## Формулы

| Расчёт | Формула |
|--------|---------|
| Инициатива | max(8, ЛВ + штраф) + 1d6 |
| HP | (СЛ + ЗД) × 4 |
| ОП | ⌊ЛВ / 2⌋ |
| Урон | (СЛ + 1d6) + оружие − броня (мин 1) |

## Справка

- Минимум ЛВ = 8 (везде!)
- Штрафы брони: Легкая −0, Средняя −2, Тяжелая −4
- Бонусы оружия: Малое +1, Среднее +4, Тяжелое +7
- Бонусы умения: L1 −6, L2 +1, L3 +2, L4 +4
