# Combat Calculator

Быстрые расчёты для боевой системы.

## Использование

```
/combat-calculator initiative ЛВ=12 броня=light
/combat-calculator damage СЛ=13 оружие=меч броня=кольчуга
/combat-calculator hp СЛ=14 ЗД=12
/combat-calculator attack СЛ=12 умение=2
/combat-calculator movement ЛВ=13 броня=heavy
/combat-calculator magic ИН=13 умение=3
```

## Команды

### initiative
Инициатива в бою: max(8, ЛВ + штраф брони) + 1d6

### damage
Урон от атаки: (СЛ + 1d6) + бонус оружия − СУ брони (минимум 1)

### hp
Очки здоровья: (СЛ + ЗД) × 4

### attack
Целевое число для атаки: Характеристика + бонус умения

### movement
Очки передвижения: ⌊ЛВ / 2⌋

### magic
Целевое число для магии: ИН + бонус умения магии

## Справочные данные

**Штрафы ловкости от брони:**
- Легкая (Light): −0
- Средняя (Medium): −2
- Тяжелая (Heavy): −4

**Бонусы оружия к урону:**
- Малое: +1
- Среднее: +4
- Тяжелое: +7

**Бонусы умения к ТЧ:**
- Уровень 1: убирает −6 штраф
- Уровень 2: +1
- Уровень 3: +2
- Уровень 4: +4

**Критические результаты:**
- 3–4: Критический успех
- 17–18: Критический провал

**Важно:** Минимум ЛВ = 8 во всех расчётах!
