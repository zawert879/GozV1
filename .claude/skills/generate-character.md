# Generate Character

Создать сбалансированного персонажа Game of Zawert по концепции.

## Использование

```
/generate-character [описание персонажа] [бюджет ОП]
```

## Примеры

- `/generate-character ловкий эльф-вор`
- `/generate-character сильный варвар-воин 50`
- `/generate-character хитрый маг огня с защитой 70`

## Процесс

Я буду:
1. Анализировать концепцию персонажа
2. Распределять ОП между четырьмя характеристиками (СЛ, ЛВ, ИН, ЗД)
3. Выбирать 3-4 основных умения, 1-2 вторичных
4. Рассчитывать HP, ОП, инициативу
5. Назначать стартовое снаряжение (независимо от умений)
6. Показывать полную математику бюджета

## Правила

- Диапазон характеристик: 8–14
- Базовое значение: 10
- Стоимость ±1: 8 ОП
- Умения уровня 1–4: 2/4/8/16 ОП (накопительно)
- По умолчанию бюджет: **50 ОП**
