# /generate-character

Генерирует сбалансированного персонажа для Game of Zawert.

## Использование

```
/generate-character "Ловкий эльф-вор с кинжалами" 50
```

## Параметры

- **Концепция** (обязательно): описание персонажа (раса, класс, стиль боя)
- **Бюджет ОП** (опционально): 30, 50, 70, 100 (по умолчанию 50)

## Процесс создания

Следует алгоритму из **GOZ_Framework/1_Character_Creation.md** (Шаги 1–7):

1. **Концепция** — анализирует описание персонажа
2. **Характеристики** — распределяет ОП между СЛ, ЛВ, ИН, ЗД (диапазон 8–14)
3. **Вторичные параметры** — рассчитывает HP, ОП, инициативу
4. **Умения** — выбирает 3–4 основных, 1–2 вторичных умения
5. **Снаряжение** — назначает тематичное стартовое снаряжение (независимо от умений!)
6. **Проверка** — показывает математику: потрачено = N ОП

## Результат

Таблица с:
- Характеристиками (СЛ, ЛВ, ИН, ЗД)
- HP, ОП, инициативой
- Умениями и их уровнями
- Снаряжением
- Полным расчётом: Характеристики (X ОП) + Умения (Y ОП) = Z ОП

## Справка по правилам

- **Стоимость характеристик**: +1 = 8 ОП → GOZ_Framework/1_Character_Creation.md § Шаг 3
- **Уровни умений**: 1–4, стоимость 2/4/8/16 ОП → GOZ_Framework/1_Character_Creation.md § Шаг 5
- **Магия**: каждое умение независимо → GOZ_Framework/5_Magic_System.md
- **Снаряжение**: независимо от умений → GOZ_Framework/1_Character_Creation.md § Шаг 6
