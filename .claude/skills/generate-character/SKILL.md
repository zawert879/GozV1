# Generate Character

Создать персонажа Game of Zawert с полными расчётами.

## Использование

```
/generate-character "ловкий эльф-вор" 50
/generate-character "сильный варвар" 70
/generate-character "хитрый маг огня"
```

## Процесс

1. Анализирую концепцию персонажа
2. Распределяю ОП между СЛ, ЛВ, ИН, ЗД (диапазон 8–14)
3. Выбираю 3–4 основных умения, 1–2 вторичных
4. Рассчитываю HP, ОП, инициативу
5. Назначаю стартовое снаряжение
6. Показываю полную математику: Характеристики (X ОП) + Умения (Y ОП) = Z ОП

## Параметры

- **Концепция**: описание персонажа (обязательно)
- **Бюджет ОП**: 30, 50, 70, 100 (по умолчанию 50)

## Ключевые правила

- Минимум/максимум характеристики: 8–14
- Базовое значение: 10
- Стоимость ±1 характеристики: 8 ОП
- Умения: уровни 1–4, стоимость 2/4/8/16 ОП (накопительно)
- Снаряжение полностью независимо от умений
