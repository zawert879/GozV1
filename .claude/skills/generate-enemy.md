# /generate-enemy

Генерирует сбалансированного врага или НИП для Game of Zawert.

## Использование

```
/generate-enemy "Боевик: ордынский воин" fighter
/generate-enemy "Босс: паладин" boss
/generate-enemy "Моб: гоблин" mob
```

## Параметры

- **Концепция** (обязательно): описание врага
- **Уровень** (обязательно): `mob`, `fighter`, `boss`, `legendary`

## Уровни и бюджеты

| Уровень | ОП | Назначение |
|---------|-----|-----------|
| **Моб** | 10–20 | Слабые враги для массовых боёв |
| **Боевик** | 30–40 | Обычные враги, достойные противники |
| **Босс** | 50–70 | Главные враги, значительные противники |
| **Легендарный** | 80–100+ | Практически невозможные враги |

## Процесс создания

Следует алгоритму из **GOZ_Framework/8_NPC_and_Enemy_Generation.md** (Шаги 1–6):

1. **Концепция** — анализирует описание врага
2. **Бюджет ОП** — выбирает в соответствии с уровнем
3. **Характеристики** — распределяет ОП по архетипу
4. **Умения** — выбирает 3–4 основных умения
5. **Снаряжение** — назначает броню, оружие, предметы
6. **Вторичные параметры** — HP, ОП, инициатива

## Результат

- Таблица характеристик, HP, инициативы, ОП
- Список умений с уровнями
- Снаряжение (броня + оружие)
- Полный расчёт: Характеристики + Умения = Бюджет ОП
- **Для боевого баланса**: рекомендация сложности для группы из 4 персонажей

## Справка по правилам

- **Архетипы**: Воин, Вор, Маг, Паладин → GOZ_Framework/8_NPC_and_Enemy_Generation.md § Шаблоны Архетипов
- **Боевой баланс группы**: 4 героя (50 ОП каждый = 200 ОП) → GOZ_Framework/8_NPC_and_Enemy_Generation.md § Правило для Групп
  - Легко: враги 100–120 ОП суммарно
  - Сбалансировано: враги 140–160 ОП суммарно
  - Сложно: враги 180–200+ ОП суммарно
- **Специальные враги**: Драконы, Армии → GOZ_Framework/8_NPC_and_Enemy_Generation.md § Специальные Враги
