# Generate Enemy

Создать врага или НИП для Game of Zawert.

## Использование

```
/generate-enemy [описание врага] [уровень]
```

## Примеры

- `/generate-enemy боевик воин mob`
- `/generate-enemy паладин в латах boss`
- `/generate-enemy маг огня fighter`
- `/generate-enemy древний дракон legendary`

## Уровни

| Уровень | ОП | Использование |
|---------|-----|----------------|
| **mob** | 10–20 | Слабые враги, мобы |
| **fighter** | 30–40 | Обычные враги |
| **boss** | 50–70 | Главные враги |
| **legendary** | 80–100+ | Практически невозможно |

## Процесс

Я буду:
1. Анализировать концепцию врага
2. Распределять ОП по уровню
3. Выбирать характеристики по архетипу
4. Выбирать 3–4 умения
5. Назначать броню и оружие
6. Рассчитывать HP, ОП, инициативу

## Баланс

Для группы из 4 героев (50 ОП каждый = 200 ОП):
- **Легко**: враги 100–120 ОП
- **Сбалансировано**: враги 140–160 ОП
- **Сложно**: враги 180–200+ ОП
