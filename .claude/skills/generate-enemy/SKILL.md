# Generate Enemy

Создать врага или НИП с правильным ОП бюджетом.

## Использование

```
/generate-enemy "воин в кольчуге" fighter
/generate-enemy "паладин в латах" boss
/generate-enemy "маг огня" mob
/generate-enemy "древний дракон" legendary
```

## Уровни врагов

| Уровень | ОП | Использование |
|---------|-----|----------------|
| **mob** | 10–20 | Слабые враги, мобы для массовых боёв |
| **fighter** | 30–40 | Обычные враги, достойные противники |
| **boss** | 50–70 | Главные враги, значительные противники |
| **legendary** | 80–100+ | Практически невозможные враги |

## Процесс

1. Анализирую концепцию врага
2. Распределяю ОП по уровню между характеристиками
3. Выбираю 3–4 основных умения по архетипу
4. Назначаю броню и оружие
5. Рассчитываю HP, ОП, инициативу

## Боевой баланс

Для группы из 4 персонажей (50 ОП каждый = 200 ОП):
- **Легко**: враги 100–120 ОП суммарно
- **Сбалансировано**: враги 140–160 ОП суммарно
- **Сложно**: враги 180–200+ ОП суммарно
