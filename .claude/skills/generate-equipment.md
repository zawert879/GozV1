# Generate Equipment

Создать предмет или снаряжение с правильным балансом.

## Использование

```
/generate-equipment [название предмета] [уровень]
```

## Примеры

- `/generate-equipment ледяной клинок medium`
- `/generate-equipment боевой топор heavy`
- `/generate-equipment кожаная броня small`
- `/generate-equipment посох архимага legendary`

## Уровни

| Уровень | Базовый ОБ | Примеры |
|---------|-----------|---------|
| **small** | 5 | Ножи, кинжалы, легкая броня |
| **medium** | 15 | Мечи, кольчуги, средняя броня |
| **heavy** | 25 | Двуручные мечи, латы |
| **legendary** | 30+ | Магические артефакты, уникальные |

## Процесс

Я буду:
1. Выбирать уровень и базовый ОБ
2. Определять базовый эффект (урон или броня)
3. Добавлять механические теги для баланса
4. Проверять: итоговый ОБ ≈ базовый ±2–3
5. Определять цену в Флоринах

## Теги

Примеры положительных: [Точное] +5, [Бронебойное] +8
Примеры отрицательных: [Неточное] −5, [Перезарядка] −6
