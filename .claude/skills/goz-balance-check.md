# GOZ Balance Checker

Проверить баланс персонажа, предмета или группы на соответствие правилам.

## Использование

```
/goz-balance-check [содержимое для проверки]
```

## Для персонажей проверяется

- Сумма потраченных ОП = ровно 50?
- Все вторичные параметры рассчитаны правильно?
- Снаряжение соответствует умениям?
- Характеристики в диапазоне 8-14?
- HP = (СЛ + ЗД) × 4?

## Для предметов проверяется

- Итоговое ОБ соответствует базовому уровня (±2-3)?
- Все теги учтены и сбалансированы?
- Цена соответствует уровню и ОБ?
- Нет очевидно переусиленных или недоусиленных элементов?

## Результат

Я верну:
- Подробный анализ каждого аспекта
- Выявленные проблемы
- Рекомендации по улучшению
- Исправленную версию если нужна
