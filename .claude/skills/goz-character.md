# GOZ Character Generator

Создать персонажа Game of Zawert по концепции пользователя.

## Использование

```
/goz-character [описание концепции персонажа]
```

## Примеры

- `/goz-character ловкий эльф-вор со знанием магии`
- `/goz-character сильный варвар, глупый, но харизматичный`
- `/goz-character умный маг, специализирующийся на защитных заклинаниях`

## Процесс

Я буду:
1. Анализировать концепцию и определять сильные/слабые стороны
2. Распределять 50 ОП между характеристиками и умениями
3. Выбирать 3-4 основных умения, 1-2 вторичных
4. Назначать тематическое стартовое снаряжение
5. Рассчитывать все вторичные параметры (HP, Инициатива, Движение)
6. Возвращать результат в виде таблицы с полными расчётами

## Критическое правило

**Сумма потраченных ОП должна быть ровно 50!** Я всегда покажу полную математику.
