# GOZ Sample Adventure Expansion

Добавить одобренный контент в Sample_Adventure.md с сохранением формата.

## Использование

```
/goz-expansion [одобренный контент для добавления]
```

## Процесс

Я буду:
1. Проверять, что контент одобрен пользователем
2. Определять правильный раздел для добавления
3. Сохранять существующий формат таблицы
4. Обновлять комментарии ОБ если используются новые теги
5. Убедиться, что новый контент не нарушает баланс

## Правила

- **ТОЛЬКО после одобрения** - контент должен быть протестирован пользователем
- Сохраняйте формат таблицы Markdown
- Обновляйте ОБ комментарии
- Проверяйте, что всё вписывается в существующую систему

## Результат

Я верну:
- Полную обновленную таблицу для раздела
- Инструкции где именно добавлен контент
- Подтверждение что всё сохранено правильно
