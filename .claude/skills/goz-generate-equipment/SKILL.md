# Generate Equipment

Создать предмет с правильным балансом по системе ОБ.

## Использование

```
/generate-equipment "ледяной клинок" medium
/generate-equipment "боевой топор палача" heavy
/generate-equipment "магический посох" legendary
/generate-equipment "кожаная броня" small
```

## Уровни и базовый ОБ

| Уровень | Базовый ОБ | Примеры |
|---------|-----------|---------|
| **small** | 5 | Ножи, кинжалы, легкая броня |
| **medium** | 15 | Мечи, кольчуги, средняя броня |
| **heavy** | 25 | Двуручные мечи, латы, тяжёлая броня |
| **legendary** | 30+ | Магические артефакты, уникальные предметы |

## Процесс

1. Выбираю уровень и базовый ОБ
2. Определяю базовый эффект (урон для оружия или СУ для брони)
3. Добавляю тематические теги (описательные, без ОБ стоимости)
4. Добавляю механические теги для баланса (положительные + отрицательные)
5. Проверяю: итоговый ОБ ≈ базовый ±2–3
6. Определяю цену в Флоринах

## Примеры тегов

**Положительные (добавляют ОБ):**
- [Точное] +5 — +1 к атаке
- [Бронебойное] +8 — игнорирует часть брони
- [Зональное] +7 — поражает несколько врагов

**Отрицательные (вычитают ОБ):**
- [Неточное] −5 — сложнее попасть
- [Перезарядка] −6 — требует действие на перезарядку
- [Неудобное] −4 — сложнее держать
