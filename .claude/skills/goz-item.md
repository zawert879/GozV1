# GOZ Item Generator

Создать предмет или снаряжение для Game of Zawert с полной балансировкой по ОБ.

## Использование

```
/goz-item [описание предмета для сеттинга]
```

## Примеры

- `/goz-item ледяной посох среднего уровня для фэнтези`
- `/goz-item кибернетическое оружие малого уровня для киберпанка, быстрое и точное`
- `/goz-item магический щит тяжелого уровня с отражением`

## Процесс

Я буду:
1. Выбирать уровень (Tier: Малый, Средний, Тяжелый, Легендарный)
2. Определять подходящие теги (положительные и отрицательные)
3. Рассчитывать базовое ОБ для уровня
4. Применять теги и проверять итоговое ОБ
5. Убедиться, что итоговое ОБ ≈ базовому (±2-3 допустимо)
6. Возвращать в виде строки таблицы Markdown

## Критические правила

- Итоговое ОБ должно соответствовать базовому уровня
- Все теги должны быть сбалансированы
- Мощные положительные теги требуют отрицательных
