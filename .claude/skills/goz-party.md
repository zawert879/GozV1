# GOZ Party Generator

Создать сбалансированную группу персонажей для приключения.

## Использование

```
/goz-party [описание нужной группы]
```

## Примеры

- `/goz-party группа из 4 персонажей: воин, маг, вор и целитель`
- `/goz-party группа для киберпанка: лидер, боец, хакер, медик`
- `/goz-party 3 персонажа для исследования подземелья`

## Процесс

Я буду:
1. Создавать каждого персонажа как целостного бойца
2. Убедиться, что они дополняют друг друга ролями
3. Проверить баланс группы (нет ли переусиленных)
4. Убедиться, что группа может справиться с разными ситуациями
5. Дать рекомендации по тактике и взаимодействию

## Для каждого персонажа

- Название и концепция
- Основные характеристики
- Ключевые умения
- HP и вторичные параметры
- Роль в группе
- Взаимодействие с другими членами
