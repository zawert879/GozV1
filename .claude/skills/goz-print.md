# GOZ Print Formatter

Подготовить контент для печати на бумагу в оптимальном формате.

## Использование

```
/goz-print [контент для форматирования под печать]
```

## Примеры

- `/goz-print подготовь шпаргалку по боевой системе на одну страницу`
- `/goz-print оптимизируй таблицу умений для печати`
- `/goz-print создай карточку персонажа для печати`

## Процесс оптимизации

Я буду:
1. Использовать компактный, читаемый формат
2. Заменять длинные тексты на таблицы где возможно
3. Разбивать на логические секции с заголовками
4. Включать краткие справочники и шпаргалки
5. Убедиться, что всё поместится на 1-2 страницы формата A4

## Для печати

- Без излишних пробелов
- Четкая иерархия заголовков
- Таблицы вместо текста
- Легкая для чтения шрифт-размер
- Оптимизация под черно-белую печать
