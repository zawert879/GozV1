# GOZ Rules Explainer

Объяснить правило Game of Zawert с примерами и контекстом.

## Использование

```
/goz-rules [вопрос о правилах]
```

## Примеры

- `/goz-rules как рассчитывается броня и инициатива`
- `/goz-rules можно ли менять умения после создания персонажа`
- `/goz-rules объясни систему откатов способностей`

## Процесс

Я буду:
1. Находить релевантный раздел в GOZ_v1_Rules.md
2. Давать чёткое объяснение правила
3. Приводить примеры из Sample_Adventure.md если применимо
4. Объяснять намерение за правилом (почему оно есть)
5. Давать совет по применению в игре

## Формат ответа

- Четкое определение
- Математика и примеры расчётов
- Примеры из игры
- Советы по использованию
- Частые ошибки
