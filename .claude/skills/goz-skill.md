# GOZ Skill Creator

Создать новое умение для Game of Zawert, соответствующее существующим.

## Использование

```
/goz-skill [описание умения]
```

## Примеры

- `/goz-skill способность поглощения магии, защитное умение`
- `/goz-skill боевой рывок, позволяет быстро атаковать несколько врагов подряд`
- `/goz-skill умение призыва питомца на помощь`

## Процесс

Я буду:
1. Определять тип умения (боевое, магическое, социальное, профессиональное)
2. Выбирать связанную характеристику
3. Описывать эффект и использование
4. Указывать предварительные условия (если есть)
5. Давать примеры применения
6. Соответствовать стилю умений из GOZ_Skills_and_Items.md

## Правила

- Используйте русские названия
- Описания должны быть ясными и краткими
- Эффекты должны быть измеримы в игровых терминах
