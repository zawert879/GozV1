## Темы

### character-creation
Создание персонажа, характеристики, умения.

**Файл**: GOZ_Framework/1_Character_Creation.md

**Содержит**:
- Шаги 1–7 создания персонажа
- Бюджет ОП (по умолчанию 50)
- Четыре основные характеристики (СЛ, ЛВ, ИН, ЗД)
- Диапазон 8–14, база 10
- Стоимость изменения характеристик: ±1 = ±8 ОП
- Формулы вторичных параметров (HP, ОП, инициатива)
- Система умений: уровни 1–4, стоимость 2/4/8/16 ОП
- Стартовое снаряжение (независимо от умений!)
- Пример: Боевой маг

### skills-and-checks
Система проверок, критики, откаты способностей.

**Файл**: GOZ_Framework/2_Skills_and_Checks.md

**Содержит**:
- Универсальная система проверок: 3d6 против ТЧ
- Успех: бросок ≤ ТЧ
- Критический успех (3–4): гарантированное попадание
- Критический провал (17–18): осложнение + возможный урон себе
- Откаты способностей: зависит от мощности (слабая 0–1, сильная 5+ раундов)
- Откат считается для каждого умения отдельно
- Магия подчиняется тем же правилам

### combat-system
Боевая система, инициатива, действия в бою.

**Файл**: GOZ_Framework/3_Combat_System.md

**Содержит**:
- Структура раунда: инициатива, ходы, разрешение эффектов
- Инициатива: max(8, ЛВ + штраф) + 1d6
- Очки передвижения: ⌊ЛВ / 2⌋
- Шесть основных действий:
  1. **Атака** — одна атака в ближнем/дальнем бою
  2. **Рывок** — удвоить очки передвижения
  3. **Отход** — безопасный выход из ближнего боя (без провоцированной атаки)
  4. **Прицеливание** — +3 к следующей атаке
  5. **Полная защита** — +2 к СУ до следующего хода, нельзя атаковать
  6. **Использование умения/предмета** — кастовать заклинание, пить зелье
- Провоцированная атака: враг атакует при выходе из ближнего боя без Отхода
- Проверка попадания: ТЧ = Характеристика атакующего + бонус умения
- Урон: (СЛ + 1d6) + бонус оружия − СУ брони (мин 1)
- Критический урон: определяет МИ (макс урон, удвоение, или другой эффект)

### equipment-and-armor
Броня, оружие, снаряжение, система ОБ.

**Файл**: GOZ_Framework/4_Equipment_and_Armor.md

**Содержит**:
- Три типа брони:
  - Легкая: СУ 2, штраф ЛВ −0
  - Средняя: СУ 5, штраф ЛВ −2
  - Тяжелая: СУ 8, штраф ЛВ −4
- **КРИТИЧЕСКИ**: ЛВ не может быть ниже 8 в любом расчёте
- Оружие по уровням: Малое (+1), Среднее (+4), Тяжелое (+7)
- Теги оружия: [Точное], [Сбалансированное], [Одноручное], [Двуручное], [Скрытное], [Шумное], [Бронебойное], [Зональное]
- Снаряжение и умения **полностью независимы**
- Щиты: нет механических параметров (только нарратив)
- Система Очков Баланса (ОБ): базовые значения 5/15/25, теги добавляют/вычитают
- Стартовый капитал: 100 Флоринов (фиксированно)

### magic-system
Магия как умение, школы магии, заклинания.

**Файл**: GOZ_Framework/5_Magic_System.md

**Содержит**:
- Фундаментальное правило: **Магия = Умение** (нет отдельных правил)
- Характеристика: Интеллект (ИН)
- Проверка: 3d6 против ТЧ (как все умения)
- **ВАЖНО**: Нет "школ магии", каждое умение уникально и независимо
- Примеры: "Огненный шар", "Исцеление", "Телепортация" — каждое отдельное умение
- Уровни умений: 1–4, накопительная стоимость 2/4/8/16 ОП
- Таблица: ТЧ для магии зависит от уровня умения (8–14 для персонажа с ИН 10)
- Уровни заклинаний: слабые (0–1 раунд), средние (2–3 раунда), мощные (4–5 раундов), очень мощные (5+ раундов)
- Критический успех: максимальный эффект
- Критический провал: осложнение, урон самому магу

### equipment-generation
Алгоритм генерации снаряжения.

**Файл**: GOZ_Framework/6_Equipment_Generation.md

**Содержит**:
- Пошаговый алгоритм создания предмета (6 шагов)
- Уровни: Малый (5 ОБ), Средний (15 ОБ), Тяжелый (25 ОБ), Легендарный (30+)
- Процесс балансировки: базовый ОБ ± теги = итоговый ОБ (±2–3 от базы)
- Стоимость положительных тегов: [Точное] +5, [Сбалансированное] +3, [Бронебойное] +8, [Зональное] +7
- Стоимость отрицательных тегов: [Неточное] −5, [Неудобное] −4, [Шумное] −2, [Двуручное] −3, [Перезарядка] −6
- Цены по ОБ: 1–5 (5–20 Ф), 6–10 (20–50 Ф), 11–15 (50–150 Ф), 16–20 (150–500 Ф), 21–25 (500–2000 Ф), 26–30 (2000–5000 Ф)

### economy
Валюта, цены, награды, задания.

**Файл**: GOZ_Framework/7_Economy.md

**Содержит**:
- Валюта: Флорины (универсальная, масштабируется под сеттинг)
- Стартовый капитал: **100 Флоринов** (фиксированно, без случайности)
- Ценовые уровни: Повседневные (1–10 Ф), Стандартные (10–100 Ф), Качественные (100–1000 Ф), Люкс (1000–10000 Ф), Легендарные (10000+ Ф)
- Награды за квесты: Простые (50–200 Ф), Стандартные (200–1000 Ф), Сложные (1000–5000 Ф), Эпические (5000+ Ф)
- Ежедневные расходы группы из 4: ~50 Ф (еда, жилище, припасы)

### npc-and-enemy-generation
Генерация НИП и врагов.

**Файл**: GOZ_Framework/8_NPC_and_Enemy_Generation.md

**Содержит**:
- Уровни НИП: Моб (10–20 ОП), Боевик (30–40 ОП), Босс (50–70 ОП), Легендарный (80–100+ ОП)
- Те же правила создания, что и для персонажей игроков
- Боевой баланс для группы из 4 персонажей (50 ОП каждый = 200 ОП):
  - Легко: враги 100–120 ОП суммарно
  - Сбалансировано: враги 140–160 ОП суммарно
  - Сложно: враги 180–200+ ОП суммарно
- Архетипы: Воин, Вор, Маг, Паладин с примерами параметров
- Специальные враги: Драконы (80+ ОП), Армии (тактический баланс)
