# Rules Reference

Справка по всем правилам Game of Zawert.

## Использование

```
/rules-reference [тема]
```

## Темы

- `character` — создание персонажа, характеристики
- `skills` — система проверок, умения, критики
- `combat` — боевая система, инициатива, действия
- `armor` — броня, оружие, снаряжение
- `magic` — магия как умение, заклинания
- `equipment` — генерация предметов, система ОБ
- `economy` — валюта, цены, награды
- `enemies` — создание врагов и НИП

## Примеры

- `/rules-reference character` — шаги создания персонажа
- `/rules-reference combat` — инициатива, действия, урон
- `/rules-reference magic` — система магии, заклинания
- `/rules-reference equipment` — уровни, теги, ОБ
