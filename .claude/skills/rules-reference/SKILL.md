# Rules Reference

Справка по правилам Game of Zawert.

## Использование

```
/rules-reference character
/rules-reference combat
/rules-reference magic
/rules-reference equipment
/rules-reference armor
/rules-reference skills
/rules-reference economy
/rules-reference enemies
```

## Темы справки

### character
Создание персонажа, характеристики, умения, вторичные параметры.
**Файл:** 1_Character_Creation.md

### skills
Система проверок 3d6, критики, откаты способностей.
**Файл:** 2_Skills_and_Checks.md

### combat
Боевая система, инициатива, ходы, действия, провоцированные атаки.
**Файл:** 3_Combat_System.md

### armor
Броня, оружие, снаряжение, СУ и штрафы.
**Файл:** 4_Equipment_and_Armor.md

### magic
Магия как умение, заклинания, уровни магии.
**Файл:** 5_Magic_System.md

### equipment
Генерация предметов, система ОБ, теги, цены.
**Файл:** 6_Equipment_Generation.md

### economy
Валюта (Флорины), цены, награды за квесты, ежедневные расходы.
**Файл:** 7_Economy.md

### enemies
Создание врагов и НИП, уровни, архетипы, боевой баланс.
**Файл:** 8_NPC_and_Enemy_Generation.md

## Быстрая справка

| Концепция | Значение |
|-----------|----------|
| Бюджет персонажа | 50 ОП (по умолчанию) |
| Диапазон характеристик | 8–14 |
| Стоимость ±1 характеристики | 8 ОП |
| Уровни умений | 1–4 (2/4/8/16 ОП) |
| Система проверок | 3d6 ≤ ТЧ |
| Критический успех | 3–4 |
| Критический провал | 17–18 |
| Валюта | Флорины (Ф) |
| Стартовый капитал | 100 Флоринов |
